Engineering 2025

AMCOS – Mgowelo

A multi-tenant cooperative management system for agricultural agencies – members, savings, loans, shares, payments, and governance in one platform.

Role

Backend engineer

Focus

Cooperative management system

Stack

Django, MySQL, multi-tenant

View on GitHub Discuss a similar build

Story behind the project

Cooperatives in places like Mgowelo, Iringa need digital records for members, savings, loans, and meetings. Paper workflows do not scale with compliance or audit needs.

Problem statement

SACCOs, AMCOS groups, and similar cooperatives juggle KYC, loans, savings products, mobile money, and governance without a unified system or clear role-based access.

What was built

A Django + MySQL multi-tenant SaaS with RBAC, member KYC, savings and loan workflows, share dividends, mobile money payments, double-entry accounting, meetings/elections, reporting, notifications, and audit trails.

  • Multi-tenant architecture for SACCOs, AMCOS, VICOBA, credit unions
  • Role-based access from super admin to member
  • Savings, loans, shares, and mobile money payments
  • Double-entry accounting and governance modules
  • Fraud alerts, notifications, and audit compliance

Tech used

Core tools and decisions that shaped the implementation.

Python Django MySQL HTML/CSS/JS Multi-tenant RBAC
