Before writing any code, always think about usability, accessibility, maintainability, scalability and visual quality.

This project must feel premium and production-ready.

Never choose the easiest implementation if it reduces quality.

Always follow the rules below.









Never assume requirements.

If a design decision is unclear, explain the available options, recommend the most suitable one with reasons, then implement it consistently.

Do not rush into generating code. Think about architecture first, then structure, then design, then implementation, and finally optimization.

Always review your own output before finishing. Check for design inconsistencies, accessibility issues, responsiveness, maintainability, performance problems, broken interactions, and unnecessary complexity. Refactor immediately if you find any.
